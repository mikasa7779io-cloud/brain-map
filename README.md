# Brain Map

Brain Map is a static web app for mapping recurring reaction paths and syncing personal data through Supabase.

## Files

- `index.html`
- `styles.css`
- `app.js`
- `SUPABASE_SYNC_SETUP.md`

## Data Privacy

The hosted frontend can be public, but personal records are stored in Supabase and protected by authentication and row-level security.
